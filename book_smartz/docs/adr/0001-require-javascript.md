# Browser requirements

Book Smartz features may require JavaScript, including sign-in, search, ranking, and save recovery.
This removes the requirement to maintain a separate path for browsers with JavaScript off.
Existing forms remain useful, but they do not establish a support requirement.

Pages display “Enable JavaScript to use Book Smartz” with JavaScript off.
Acceptance journeys use JavaScript and retain keyboard access, response focus, and explicit save recovery checks.
The server retains authority over authentication, authorization, ranking, and original-action outcomes.
