# Caveat

Caveat v23 by Pablo Impallari, licensed under the SIL Open Font License 1.1.
The license is published at `/caveat-OFL.txt`.

These variable WOFF2 subsets cover weights 400–700 and preserve the Google Fonts character ranges. Vite embeds them in the site stylesheet; browsers make no font service requests. Browser tests use these same assets.
